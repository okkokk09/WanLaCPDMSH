# ระบบบันทึกวันลา (Leave Management System)

ระบบบริหารจัดการและบันทึกวันลาของบุคลากร พัฒนาด้วย **React + TypeScript + Tailwind CSS** ออกแบบมาเพื่อให้ผู้ดูแลระบบ (Admin/HR) สามารถบันทึกข้อมูล ดูแลสิทธิ์วันลา และติดตามสถิติการลาได้อย่างสะดวก รวดเร็ว และสวยงาม รองรับภาษาไทยสมบูรณ์แบบ 100%

---

## ✨ ฟีเจอร์เด่นของระบบ

1. **📊 แดชบอร์ดภาพรวม (Dashboard)**
   - สรุปตัวเลขสำคัญ: จำนวนบุคลากรทั้งหมด, ผู้ที่ลาวันนี้, วันลาที่ใช้ในเดือนนี้
   - แสดงรายชื่อบุคลากรที่ลาในวันนี้แบบเรียลไทม์ พร้อมเหตุผลและประเภทการลา
   - รายการบันทึกล่าสุด พร้อมปุ่มลัดจัดการข้อมูล

2. **📝 ระบบบันทึกการลา (Leave Records)**
   - ฟอร์มบันทึกการลาที่ใช้งานง่ายและรวดเร็ว
   - ตรวจสอบยอดวันลาคงเหลือของบุคลากรแบบเรียลไทม์ พร้อมแจ้งเตือนหากวันลาเกินสิทธิ์โควตา
   - คำนวณวันลาเต็มวันอัตโนมัติ พร้อมตัวเลือกข้ามวันหยุดเสาร์-อาทิตย์
   - ค้นหาและกรองประวัติการลาตามชื่อ, กลุ่มงาน, ประเภทการลา หรือคำค้นหา
   - ส่งออกประวัติการลาเป็นไฟล์ Excel (.xlsx)

3. **📅 ปฏิทินแสดงวันลาประจำเดือน (Leave Calendar)**
   - ปฏิทินภาษาไทย แสดงชื่อเดือนและปี พ.ศ. ชัดเจน
   - แสดงแถบป้ายชื่อผู้ลาในแต่ละวัน พร้อมสีแบ่งตามประเภทการลา (เขียว=พักผ่อน, แดง=ป่วย, ส้ม=กิจ, ม่วง/ฟ้า=อื่นๆ)
   - ช่องค้นหาชื่อบุคลากรบนปฏิทินแบบเรียลไทม์ พร้อมปุ่มเคลียร์คำค้นหา
   - คลิกที่วันในปฏิทินเพื่อดูรายละเอียดผู้ลาทั้งหมดในวันนั้น หรือกดปุ่มบันทึกการลาในวันนั้นได้ทันที
   - ตัวกรองแสดงผลเฉพาะกลุ่มงาน หรือเฉพาะบุคลากรที่ต้องการ

4. **👥 การจัดการบุคลากร (Staff Management)**
   - บรรจุรายชื่อบุคลากรสำนักงานสหกรณ์จังหวัดแม่ฮ่องสอน ครบถ้วน 46 ท่าน
   - ครอบคลุมครบทั้ง 9 กลุ่มงาน พร้อมสีประจำกลุ่มงานสดใส
   - กำหนดโควตาสิทธิ์วันลาแยกตามรายบุคคลได้อย่างอิสระ (ลาพักผ่อน, ลาป่วย, ลากิจ, ลาคลอด, ลาบวช, อื่นๆ)
   - แสดงสรุปจำนวนวันที่ใช้ไปแล้ว และวันคงเหลือของแต่ละคน

5. **📈 สรุปวันลาคงเหลือ (Leave Balances)**
   - 3 การ์ดตัวชี้วัดหลัก: โควตารวมทั้งหมด, ใช้วันลาแล้วรวม, วันลาคงเหลือรวม
   - ตารางสรุปภาพรวมวันลาคงเหลือของบุคลากรทุกคน
   - แสดงวันลาแต่ละประเภท: ใช้ไปกี่วัน / โควตาทั้งหมด / คงเหลือกี่วัน
   - ส่งออกตารางสรุปวันลาคงเหลือเป็นไฟล์ Excel (.xlsx) ได้ทันที
   - รองรับการสั่งพิมพ์หน้ารายงาน (Print View)

6. **💾 การสำรองและกู้คืนข้อมูล (Backup & Restore)**
   - ข้อมูลทั้งหมดจะถูกบันทึกไว้ในเครื่องของคุณ (LocalStorage)
   - มีเมนู **"ส่งออกข้อมูลสำรอง (JSON)"** และ **"นำเข้าข้อมูลสำรอง (JSON)"** เพื่อสำรองข้อมูลหรือย้ายไปใช้งานบนเครื่องอื่น
   - มีปุ่มรีเซ็ตเป็นข้อมูลเริ่มต้นเพื่อทดสอบระบบได้ทันที

## 🚀 วิธีการเปิดใช้งานระบบบน Windows

คุณสามารถเปิดใช้งานได้ง่ายๆ ด้วยวิธีใดวิธีหนึ่งต่อไปนี้:

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์เปิดระบบ (ง่ายที่สุด)
ดับเบิ้ลคลิกที่ไฟล์ **`เปิดระบบบันทึกวันลา.bat`** หรือ **`run_app.bat`** ในโฟลเดอร์นี้ ระบบจะเปิดหน้าเว็บขึ้นมาบนเบราว์เซอร์ของคุณโดยอัตโนมัติ

### วิธีที่ 2: รันผ่าน Terminal / Command Line
เปิด Terminal ในโฟลเดอร์นี้แล้วพิมพ์:
```bash
npm run dev
```
จากนั้นเปิดเบราว์เซอร์ไปที่: `http://localhost:5173`
